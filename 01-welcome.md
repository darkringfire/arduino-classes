# Знакомство с Arduino. 

Среда разработки и первый скетч Blink

**Тема:** Arduino IDE, структура скетча, `setup` и `loop`, пример Blink.  
**Цель:** познакомить детей с платформой Arduino, научить открывать и загружать готовый скетч, понимать назначение `setup` и `loop`, изменять параметры мигания встроенного светодиода.  
**Оборудование:** Arduino UNO, USB-кабель, компьютер с Arduino IDE.

## Ход урока

### 1. Организационный момент (5 мин)
- Техника безопасности: не подключать/отключать плату во время загрузки скетча, не замыкать контакты, работать сухими руками.
- Кратко: Arduino — это маленький компьютер, который умеет управлять светодиодами, моторами, датчиками по программе.

### 2. Знакомство с Arduino IDE (10 мин)
- Запуск Arduino IDE.
- Подключение Arduino UNO по USB.
- Выбор платы: **Инструменты → Плата → Arduino Uno**.
- Выбор порта: **Инструменты → Порт → COM…**.
- Кнопки: **Проверить** (компиляция), **Загрузить** (прошивка), **Монитор порта**.

### 3. Структура скетча (10 мин)
- Скетч — это программа для Arduino.
- Обязательные части:
  - `void setup()` — выполняется **один раз** при включении или сбросе.
  - `void loop()` — выполняется **бесконечно**, пока есть питание.
- Объяснение названий:
  - `void` — от англ. *void* — «пустой». Означает, что функция ничего не возвращает.
  - `setup` — от англ. *setup* — «настройка, установка». Здесь задаются начальные настройки.
  - `loop` — от англ. *loop* — «петля, цикл». Здесь код повторяется бесконечно.
- `//` — комментарий, от англ. *comment* — «пояснение». Компьютер его игнорирует.

### 4. Разбор примера Blink (10 мин)
Открыть: **Файл → Примеры → 01.Basics → Blink**.

```cpp
void setup() {
  pinMode(LED_BUILTIN, OUTPUT); // встроенный светодиод на pin 13
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH); // включить
  delay(1000);                     // ждать 1000 мс = 1 с
  digitalWrite(LED_BUILTIN, LOW);  // выключить
  delay(1000);                     // ждать 1 с
}
```

Разбор по строкам и объяснение названий:
- `pinMode` — от англ. *pin* — «контакт, вывод» + *mode* — «режим». Устанавливает режим работы вывода.
- `LED_BUILTIN` — от англ. *LED* — «светодиод» + *built-in* — «встроенный». Константа, обозначающая встроенный светодиод (пин 13).
- `OUTPUT` — от англ. *output* — «выход». Режим вывода: плата подаёт сигнал.
- `digitalWrite` — от англ. *digital* — «цифровой» + *write* — «запись». Записывает цифровое значение на вывод.
- `HIGH` — от англ. *high* — «высокий». Высокий уровень напряжения (включить).
- `LOW` — от англ. *low* — «низкий». Низкий уровень напряжения (выключить).
- `delay` — от англ. *delay* — «задержка». Пауза в миллисекундах.

### 5. Практика: изменение задержек и количества вспышек (15 мин)
Дети загружают Blink и меняют код. Циклы `for`/`while` не используем — только повторяющиеся команды.

**Задание 1. Изменить скорость мигания**
- Сделать так, чтобы светодиод горел 100 мс и не горел 100 мс.
- Затем: горит 2000 мс, не горел 500 мс.

**Задание 2. Пять вспышек и длинная пауза**
Нужно, чтобы в `loop()` светодиод мигнул 5 раз быстро, затем была пауза 2 секунды. Команды записываем подряд, без цикла:

```cpp
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(200);

  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(200);

  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(200);

  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(200);

  digitalWrite(LED_BUILTIN, HIGH);
  delay(200);
  digitalWrite(LED_BUILTIN, LOW);
  delay(200);

  delay(2000);
}
```

**Задание 3. Сигнал SOS**
Три коротких вспышки, три длинных, три коротких, пауза.  
Короткая — 200 мс, длинная — 600 мс. Записываем все вспышки подряд.

**Задание 4. «Ускорение»**
Сделать так, чтобы длительность свечения увеличивалась: 100, 200, 300, 400, 500 мс, потом сброс.  
Каждую вспышку прописываем отдельно.

5. Что делает `delay(1000)`?
6. Что произойдёт, если убрать все `delay()`?
7. Как изменить количество вспышек?
8. Почему в примере используется `LED_BUILTIN`, а не просто число 13?
9. Чем отличается компиляция от загрузки скетча?
10. Что будет, если поставить `delay(0)`?
